# AI-Infra 中文学习阅读器

**把 AI 基础设施文档变成能读懂、能查词、能逐步学下去的中文阅读站。**

基于 [pacoxu/AI-Infra](https://github.com/pacoxu/AI-Infra) 的内容，在保留原文与出处的基础上，增加中文翻译、入门导读、术语与英语词卡，以及适配电脑和手机的阅读界面。

> **[在线阅读 → luo-root.github.io/AI-Infra](https://luo-root.github.io/AI-Infra/)** · 已通过 GitHub Actions 部署。

[项目源码 / Star](https://github.com/Luo-root/AI-Infra) · [使用说明](./learning/README.zh-CN.md) · [上游中文全景](https://github.com/pacoxu/AI-Infra/blob/main/README.zh-CN.md) · [上游英文全景](https://github.com/pacoxu/AI-Infra/blob/main/README.md)

## 为什么做这个项目

AI-Infra 的资料很多，但刚开始学时经常卡在三个地方：文章是英文、术语太密集、不知道不同组件在整套系统里分别做什么。

这个阅读器让正文保持连贯，解释按需出现：遇到不懂的词，点击或触碰即可查看小卡片，不必不停跳出文章查资料。

## 能做什么

- **中文阅读与英文对照**：完整译文、上游已有中文、英文待译和新增导读分别标记，不用摘要冒充全文翻译。
- **术语卡**：一句话解释、中文名称、英文原义、文章中的含义、学习例子与来源。
- **英语辅助**：部分词条提供音标，支持浏览器英语合成语音；选中词语可查本地词库，未收录时明确提示。
- **连续阅读**：全文检索、专题分类、学习路线、章节目录、代码复制、深浅主题和逐篇阅读位置保存。
- **更新可追溯**：原文与译文分别记录来源版本。原文更新而译文未同步时，显示醒目提示，不再宣称二者一致。
- **静态部署**：无需后端，GitHub Actions 构建和测试后可发布到 GitHub Pages。

## 从哪里开始学

建议先沿着这条链阅读，而不是先背项目名单：

**领域地图 → 一次推理请求 → Pod / GPU → 延迟与吞吐 → KV 缓存 → 从组件到平台。**

新增的学习导读位于 [`learning/content/guides/`](./learning/content/guides/)。导读是帮助理解的补充，不是原文章节的逐句翻译。

## 当前进度与边界

首批完成 6 篇完整译文；第二批补齐推理目录剩余 16 篇，涵盖模型结构、并行与 PD 分离、推理平台、模型生命周期、分发、记忆与发布门禁。另有 4 篇入门导读、30 条精选词条。覆盖数量以网站实时生成的统计为准。

- 尚未完成全量翻译；上游已有中文未全部逐句复核。
- 新译文没有经过人工专业审校，产品版本、支持矩阵和性能数字未全部独立实测。
- 系统合成语音不是真人录音，依赖设备提供英语语音。词库不是完整词典，也不保证自动判断每个多义词的语境。
- 阅读位置仅存于当前浏览器，不上传、不跨设备同步。
- 首版没有离线缓存。外链图片、外部资料和部分系统语音可能需要网络。
- Issue / PR 是资料与任务来源，不以“已关闭”替代“已实测”。筛选依据见 [`learning-plan/`](./learning-plan/)。

## 本地阅读

需要 Python 3.10+。已有构建结果时：

```powershell
python learning/scripts/serve.py
```

打开终端显示的地址，默认是 `http://127.0.0.1:4174`。这只在本机可访问。

从源码构建，需要 Node.js 22、Python 3.10+ 和 Bun 1.3.14：

```powershell
cd learning
bun install --frozen-lockfile
npm run build
python scripts/serve.py
```

`npm run build` 自动生成文档索引，静态网站输出到 `learning/dist/`。不要直接双击 HTML 代替 HTTP 服务。

## 同步、检查与发布

三条流程各管一件事：

1. **Learning CI**：对学习版代码和内容运行检查、构建与浏览器测试。
2. **Sync upstream content**：手动触发，从上游 main 同步允许范围内的已合并文档和静态资产，生成变更 PR。不覆盖项目 README、词库或译文，不自动合并、不自动翻译，也不执行上游脚本。
3. **Learning Pages**：学习版 main 更新后，通过测试再发布静态站；PR 本身不部署生产网站。

目前不配置定时同步，检查频率尚待确定。手动工作流也可能受仓库“允许 GitHub Actions 创建 PR”的设置限制；失败应明确报告，不能把没建成 PR 当成同步完成。

同步后的上游首页保存在 `learning/upstream/`。根 README 专门介绍本项目，避免被上游首页覆盖。原文内容目录保持原有结构，便于对照上游。

## 参与贡献

如果阅读器对你有帮助，欢迎 [Star](https://github.com/Luo-root/AI-Infra)。也欢迎报告：

- 翻译偏离原意、漏译或过时之处；
