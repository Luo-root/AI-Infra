# AI-Infra 中文学习阅读器

本地学习版，基于 pacoxu/AI-Infra。上游英文与既有中文正文不覆盖；新增译文与学习注释位于本目录。

## 启动

当前本机已有构建结果时，在仓库根目录运行 `python learning/scripts/serve.py`，然后打开 http://127.0.0.1:4174 ，无需安装前端依赖。解压交付包后则在解压目录运行 `python scripts/serve.py`。端口被占用时加 `--port 4180` 等其他端口。也可运行 `learning/start.ps1`（受本机 PowerShell 执行策略约束）。

要从源码重建，在仓库根目录先生成资料：

```powershell
python learning/scripts/build-library.py
cd learning
npm install
npm run dev
```

打开终端打印的本地地址。该服务默认只绑定 `127.0.0.1`，不是公网网站，手机在外网无法访问。若本机 npm 异常，可用已有 Bun 执行 `bun install`，再运行上述脚本；不需要系统级安装。

打包与预览：

```powershell
npm run build
npm run preview
```

构建输出为 `learning/dist/`。不能直接双击 HTML 代替 HTTP 预览，资料库通过 fetch 加载。

## 当前内容

- 按专题维护完整译文：推理、训练、可观测性，以及 Kubernetes 入门篇目；具体覆盖与待译数量由资料库生成统计。
- 4 篇新增学习导读：入门地图、一次推理、指标、组件与平台。
- 持续扩充的术语与英语词卡，含中文概念、缩写和复合术语；不是完整词典，词条数量不代表所有正文概念均已覆盖。
- 原仓库学习文档全库索引，已有中英配对折叠为一个阅读条目。
- 上游 Issue/PR 的筛选及后续增补状态，不把待验证实验说成已经完成。

本批译文没有经过人工专业审校；原文中的版本、产品支持和性能断言未全部独立核实。译者注与技术勘误独立显示，不偷偷改原意。

## 使用

左侧搜索标题、正文和词卡；从学习桌面的路线开始读。虚线词可点击、触摸或键盘激活；也可以选词后点“查所选词”。未收录词会明确提示。

有对应英文时可切换原文。阅读位置和主题仅保存在当前浏览器，不会同步到其他设备，也不上传。

发音使用浏览器英语合成语音，非真人录音。没有英语语音时显示不可用；有音标的条目可直接查看。外部图片、外链及部分系统语音需要网络；首版未实现离线缓存，不承诺断网可用。

## 内容更新与译文漂移

每篇译文有源路径和源提交记录，生成器比对该提交的源文与工作区源文。源文变更而译文未更新时，保留中文并标为“原文已更新，译文待同步”，不计入同步译文；来源元信息损坏或对应历史提交不可读时才拒绝构建。上游首页从 `upstream/` 读取，根 README 用于介绍阅读器项目。源文件摘要按 LF 归一化计算，不受 Windows autocrlf 影响。

修改译文后重新生成资料，再构建。后续新译文放在 `learning/content/zh/` 对应原路径中；同时补来源元信息与测试清单。

## 检查

仓库根目录：

```powershell
python -m unittest discover -s learning/tests -p 'test_*.py' -v
```

`learning/` 目录（先构建）：

```powershell
npx playwright test
```

浏览器测试使用本地预览地址，覆盖检索、中英切换、词卡、移动布局、安全净化和图表文字。没有运行实际 GPU/Kubernetes 实验。

## 目录

- `content/zh/`：完整译文。
- `content/guides/`：新增教学注释，不是翻译。
- `glossary.json`：词库及来源。
- `updates.json`：筛选后增补与待验证项目。
- `scripts/build-library.py`：只读源文，生成资料与静态图片。
- `web/`：阅读界面。
- `tests/`：内容及浏览器测试。
- `dist/`：生成的静态站，不入版本控制。
